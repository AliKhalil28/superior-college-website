# Superior College Mian Channu

A single-page Next.js site for the Mian Channu campus.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Portraits

Management photos are not on the page yet. Save each picture in `public/management/` and set its `photo` path in `lib/content.js`.

- `chairman.jpg` — Sheikh Sajjad, Chairman
- `vice-chairman.jpg` — Kashif Waheed Khan, Vice Chairman
- `ceo.jpg` — Ammir Hafeez, CEO
- `principal.jpg` — Shoaib Waheed Khan, Principal and Managing Director
- `academic-director.jpg` — Ammad Waheed Khan, Academic Director

Example: `photo: "/management/chairman.jpg"`
